## 🎯 User Flow

```
Login/SignUp
    ↓
Main Menu (6 options)
    ↓
Request Service ← (Starts wizard)
    ↓
Step 1: Select Category (Industrial/Commercial/Domestic)
    ↓
Step 2: Select Drilling Type (Symmetric/Core/Geo-Technical)
    ↓
Step 3: Select Pump Type (Submersible/Solar/Hand)
    ↓
Step 4: Enter Depth & Height (meters)
    ↓
Step 5: Add Plumbing (Optional)
    ↓
Step 6: Add Tank (Optional)
    ↓
Step 7: Review Invoice & Confirm
    ↓
Success ✓ (Saved to database)
```

## 🚀 Usage

### Launch from Main Menu
```java
JFrame wizardFrame = new JFrame("Service Request Wizard");
wizardFrame.setDefaultCloseOperation(JFrame.DISPOSE_ON_CLOSE);
wizardFrame.setSize(800, 700);
wizardFrame.setLocationRelativeTo(null);
wizardFrame.add(new ServiceRequestWizardManager(clientId));
wizardFrame.setVisible(true);
```

### Or from SignUpPage after registration
```java
// After successful registration
SignUpPage.this.dispose(); // Close signup
JFrame mainFrame = new JFrame("UZIMA - Main Menu");
mainFrame.add(new MainMenuPanel(newClientId));
mainFrame.setVisible(true);
```
