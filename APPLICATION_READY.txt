📞 QUICK TROUBLESHOOTING

Problem: "Table 'javalearning.clients' doesn't exist"
Solution: Run setup SQL again:
  mysql -u root -p"teddy" javalearning < setup_javalearning_database.sql

Problem: "Login failed" or "Client not found"
Solution: 
  • Check email spelling (admin@uzima.com)
  • Password is case-sensitive
  • Use "password123" for test accounts

Problem: "Connection refused"
Solution: Start MySQL service:
  sudo service mysql start
