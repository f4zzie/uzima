ARCHITECTURE:
========================================================

Separation of Concerns - 5 Layer Architecture:

Layer 1: UI (Presentation)
  └─ LoginPage, SignUpPage, UsersTable (UNCHANGED)

Layer 2: Services (Business Logic)
  ├─ ClientService
  ├─ InvoiceService
  └─ ServiceManagementService

Layer 3: DAO (Data Access)
  ├─ ClientDAO
  ├─ ServiceDAO
  └─ InvoiceDAO

Layer 4: Models (Data Objects)
  ├─ Client
  ├─ Invoice
  ├─ DrillingService
  ├─ PumpService
  └─ PlumbingService

Layer 5: Database
  └─ MySQL (uzima_borehole)

========================================================
INTEGRATION WITH UI:
========================================================

BEFORE (Old way - avoid):
  DBhelper.loginUser(email, password);
  DBhelper.registerUser(...);

AFTER (New way - recommended):
  Client client = ClientService.getClientByEmail(email);
  boolean success = ClientService.registerClient(...);
  List<Invoice> invoices = InvoiceService.getClientInvoices(id);

BENEFITS:
✓ Separation of concerns
